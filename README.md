# 🎴 Memory Card Game Web - Pokémon Edition 🎴

¡Bienvenido/a a **Memory Card Game Web**!  
Un juego de memoria temático de Pokémon, desarrollado junto a un colega para poner a prueba tu memoria y velocidad mientras te sumerges en el mundo Pokémon. ¡Gotta Catch 'Em All!

## 🕹️ ¿Cómo Jugar?

1. **Objetivo:** Encuentra todas las parejas de cartas iguales en el menor tiempo posible.
2. **Comienza el juego:** Haz clic sobre una carta para voltearla.
3. **Busca la pareja:** Voltea otra carta tratando de encontrar la carta gemela (con el mismo Pokémon).
4. **¿Coinciden?**
   - **¡Sí!** Las cartas quedarán reveladas.
   - **No:** Se voltearán de nuevo tras un breve instante.
5. **Completa:** Cuando encuentres todas las parejas, ¡el juego termina!

> ⚡ **Tip:** Memoriza la ubicación de las cartas para hacer parejas más rápido 😉

---

## 🧑‍💻 ¿Cómo está hecho?

- **Componentes:**  
  - Tablero HTML dinámico generado con JavaScript.
  - Cartas ilustradas temáticamente con CSS y assets de Pokémon.
  - Animaciones y efectos usando CSS3.
  - Diseño responsive para jugar en PC y dispositivos móviles.

- **Lógica:**  
  - Barajado aleatorio en cada partida.
  - Control de estado para cartas volteadas, parejas encontradas y reinicio del juego.
  - Posible contador de tiempo, movimientos y otros retos (añade detalles personalizados si tu juego los tiene).
